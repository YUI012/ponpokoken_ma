## 改めて結論

Agent Skillsは、プロンプトをゼロにする機能ではなく、繰り返しの前提・手順を再利用しやすくする仕組みです。

毎回違う仕事まで無理にSkill化すると、かえって管理が複雑になります。

**まず1つの定型作業をSkill化し、通常プロンプトと比べて修正回数が減るか確認してください。**
