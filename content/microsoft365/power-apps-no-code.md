# Power Appsはプログラミング未経験でも作れる？3人の実例で検証

## 結論

プログラミング未経験・非エンジニアの立場からPower AppsやPower Platformで業務アプリを作った実例はある。基本的なキャンバスアプリは始められる一方、関数・データ設計・複雑な要件では学習が必要になるため「コード経験ゼロでも何でも簡単」とまでは言えない。

## 3人の実例

### 事例1
- 開始点：一般事務から社内SEへ移り、プログラミング未経験と記載 / 方法：Power AppsやPower Automateを業務改善に利用 / 結果：Power Platformを実務スキルとして活用

### 事例2
- 開始点：プログラミング専門家ではない現場オペレーター / 方法：現場課題をPower Appsで小さくアプリ化 / 結果：非エンジニア視点で作成手順を整理

### 事例3
- 開始点：アプリ開発は言語知識と時間が必要だと思っていた / 方法：Power Appsで簡易勤怠アプリを試作 / 結果：短時間で簡単なアプリを作成できたと記載

## 3人の比較から分かること

- プログラミング専門家ではない状態から始めている
- 業務上の小さな課題を題材にしている
- テンプレートや簡単なキャンバスアプリから触る
- ボタン・フォーム・保存の基本操作を先に覚える
- 分からない関数だけ都度小さく試す

注意点もあります。
- 複雑なデータモデルや高度な式は別途学習が必要
- 組織の環境・コネクタ権限でできることが変わる
