# OutlookをUdemyで学ぶ価値ある？自己流との違いを3人の実例で検証

## 結論

Outlookは触りながら覚えることもできるためUdemyが必須とは言えない。ただし、メール整理・検索・予定表など複数機能を自己流で個別に覚えるより、全体を体系的に確認したい人には講座で学ぶ価値がある可能性がある。

[引用元を見る](https://allabout.co.jp/gm/gc/63878/)

## 3人の比較から分かること

- Outlookにはメール以外にも予定表・検索・ルールなど複数の実務機能がある
- 自己流だと使わない機能が残りやすい
- 基本メール→整理・検索→予定表の順に一巡する
- 無料情報で十分なら無理に有料講座を買わない
- 学習順を自分で作るのが面倒なら講座を使う

注意点もあります。
- 3例はUdemy受講者レビューではない
- Udemy購入の必要性を直接証明するものではない
