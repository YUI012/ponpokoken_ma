# Microsoft 365 Copilotを使う前に何を学ぶべき？3人の実例で検証

## 結論

導入初期には、Microsoft 365各アプリの基本操作だけでなく、社内データの扱い、ライセンス差、プロンプトの出し方で迷う実例がある。全アプリを先に習得する必要はないが、「使うアプリの基本」「安全なデータ利用」「目的・背景・形式を含む指示」の3点を押さえると始めやすい。

## 3人の実例

### 事例1
- 開始点：Copilot Chatを使い始めた初心者 / 課題：会社情報の入力可否やライセンス差が分からなかった / 方法：メール・文章・Excel用途を試しつつ利用ルールを確認

### 事例2
- 開始点：社内導入前に自宅で予習 / 方法：利用できる機能と基本操作を先に確認 / 結果：導入後すぐ試せるよう基礎を整理

### 事例3
- 課題：Copilotの出力が期待とずれる / 方法：目的・背景・期待する形式・参照元を明確にする / 結果：プロンプトの構造を見直す重要性を整理

## 3人の比較から分かること

- 使い始める前後に機能・ルール・指示方法を確認している
- Copilotの性能だけでなく入力側の条件が結果に影響している
- まず日常で使うTeams/Outlook/Word等の基本操作を確認する
- 会社のAI利用ルールと入力可能データを確認する
- 目的・背景・出力形式を入れた短いプロンプトから試す

注意点もあります。
- 利用ルールは組織ごとに異なる
- プロンプト技術だけで誤回答を完全に防げるわけではない
