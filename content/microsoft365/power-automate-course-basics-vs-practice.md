# Power Automate講座は基礎と実践どっちを買う？3人の目的で比較

## 結論

Power Automate未経験でトリガーやアクションの考え方から学びたい人は基礎型、すでに自動化したい業務が明確な人は実践型が合いやすい。実例でも、基礎概念を小さく学ぶケースと、申請・通知など具体業務から作るケースに分かれる。

## 3人の実例

### 事例1
- 目的：Power Automate初心者 / 学び方：処理を一つ作りながら学習 / 向いている人：基礎型向き

### 事例2
- 目的：業務効率化の入口 / 学び方：勤怠リマインドという単純フロー / 向いている人：基礎から実作業へ橋渡し

### 事例3
- 目的：通知・テンプレメールを自動化 / 学び方：申請投稿やExcel選択行を起点に実装 / 向いている人：具体業務を作る実践型向き

## 3人の比較から分かること

- 目的の明確さで必要な学習深度が変わる
- 小さなフローから具体業務へ進む流れが共通
- 用語や基本構造が不安なら基礎型
- 自動化対象が具体的なら作例中心の実践型
- 講座のサンプル業務が自分の仕事に近いか確認する

注意点もあります。
- 3人はUdemy講座自体を比較したわけではない
- 講座名ではなくカリキュラムと前提知識を確認する
