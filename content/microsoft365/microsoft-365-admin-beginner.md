## 3人の比較から分かること

- ユーザー・ライセンス・管理者ロールを基礎領域として扱っている
- 管理画面や実機で設定を確認しながら学んでいる
- テナントと管理センターの構成を把握する
- ユーザー作成→ライセンス付与→ロール確認を実機で試す
- 次にExchange/Teams/セキュリティ/コンプライアンスへ範囲を広げる

注意点もあります。
- 本番テナントでは影響範囲の大きい設定を安易に変更しない
- Microsoft Learnと変更履歴で最新仕様を確認する

## Microsoft 365 Administratorで体系的に学ぶなら

**Microsoft 365 Administrator**

- Microsoft 365の構成・ロールとAdmin Center操作を扱う

- Exchange Online・メールフロー・セキュリティ・コンプライアンスを扱う
- PowerShellを使う管理タスクも含む
