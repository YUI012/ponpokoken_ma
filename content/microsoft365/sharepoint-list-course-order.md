# SharePointリスト講座は基礎講座の後に買うべき？3人の学習順で検証

## 結論

SharePointを初めて触る人は、サイトやページなど全体像を小さな検証サイトで理解してからリストへ進むと文脈を掴みやすい。ただし、リストだけを業務で使う目的が明確なら、必ず基礎講座を先に購入する必要までは確認できない。

## 3人の比較から分かること

- 初心者はSharePoint全体像を先に触っている
- 小さなサイトで手を動かしながら学んでいる
- SharePointが完全に初めてなら基礎を一巡する
- リストの用途が明確ならリスト講座から始めてもよい
- 必要になった時点で権限・サイト構造を補う

注意点もあります。
- 3人ともリスト講座と基礎講座の購入順を直接比較したわけではない
- 基礎講座が必須という結論ではない
