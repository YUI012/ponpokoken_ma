# Copilot Studio講座を買う価値ある？独学との違いを3人で検証

## 結論

無料記事や試行錯誤でもCopilot Studioは学べるが、実例では「何を作るか」「知識源」「指示」「公開・連携」を順番に試す中で理解している。エージェント作成を最初から最後まで一連で追いたい人には実践講座の価値がある一方、Udemyが必須という直接比較データまでは確認できない。

## 3人の実例

### 事例1
- 開始点：完成形を決めずにCopilot Studioを試用 / 方法：小さなエージェントから作って機能を探索 / 結果：できることを掴めた一方、Power Automate連携では詰まりも経験

### 事例2
- 開始点：デザイナーでAIエージェント構築は初心者 / 方法：UIガイドラインのWord文書を知識源にFAQエージェントを作成 / 結果：対象データを限定してFAQ応答を試作

### 事例3
- 作業：AI-102向け学習支援エージェント / 方法：指示・トピック・外部連携を段階的に設定 / 結果：用途を絞ったAgentを作成しMicrosoft 365 Copilotへ公開

## 3人の比較から分かること

- 実際に1つのエージェントを作りながら機能を理解している
- 作成中に知識源・指示・連携など複数要素を順に学んでいる
- 無料記事でまず1体作り、どこで詰まるか確認する
- 作成→知識追加→テスト→公開まで一連で学びたいならハンズオン講座を使う
- 受講後は自社データを使わずダミーデータで再現する

注意点もあります。
- Udemyが独学より必ず優れるという3人の直接比較ではない
- Copilot Studioは更新が速いため講座の更新日と現行UIを確認する
