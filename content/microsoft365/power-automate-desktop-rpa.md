# Power Automate Desktopを買い切りRPA代わりに使える？3人の業務例で検証

## 結論

Windows上の定型操作、Web取得、ファイル操作、システム入力などはPADでRPA化できた実例がある。一方で、既存RPA製品を無条件に置き換えられるわけではなく、無人実行・保守・ライセンス・対象アプリの安定性を要件ごとに確認する必要がある。

## 3人の実例

### 事例1
- 対象：複数RPA製品が混在する部署 / 方法：新規業務をPADでRPA化し、既存RPAもPADへ一元化 / 結果：将来の保守者の習得コストを低減

### 事例2
- 対象：スクレイピングを含む定型作業 / 方法：PADのレコーダー中心にワンクリックRPAを作成 / 結果：人手5分超の処理を約半分程度に短縮

### 事例3
- 対象：請求明細サイトへの面倒なログインとダウンロード / 方法：PADのWebレコーダーでログインから取得まで自動化 / 結果：約2分の作業を約50秒に短縮

## 3人の比較から分かること

- WindowsやWeb上の定型操作をRPAとして自動化している
- 人手の反復作業や保守対象をPADへ寄せている
- 対象業務を手順が固定された反復作業に絞る
- まず有人実行で安定性と例外パターンを確認する
- 既存RPA置換ではフロー数・保守者・実行方式を棚卸しする

注意点もあります。
- 無人実行やクラウド連携などはライセンス・環境要件を別途確認する
- UI変更が多いシステムや例外の多い業務は保守負荷が高くなる
