# クラウドセキュリティ学習ロードマップ｜AWS/Azure共通で先に学ぶこと

## 結論

ベンダー製品より先にIAM・暗号・ログ・NW・責任共有を学ぶ方がAWS/Azureの両方へ展開できる。

複数クラウドに共通する基礎としてネットワーク、IAM、責任共有、ログ等を先に学び、その後ベンダー固有サービスへ進む順番が支持される。

## ベンダー名より先にネットワーク・IAM・責任共有を固める

クラウドセキュリティを学ぶ前に、LinuxやTCP/IPなどインフラ基礎が必要です。その上でIAM、責任共有、暗号、ログ・監視といったAWS/Azureに共通する考え方を押さえると、サービス名が変わっても応用できます。

共通概念を理解した後にAWSのSecurity HubやAzureのDefender、Sentinelなどへ進む方が、製品暗記になりにくいです。最初から全サービスを網羅する必要はありません。
