## 3講座は日本語総合・クラウド全般・AWS特化で分ける

クラウドセキュリティ講座は、扱うクラウドと学習範囲で選ぶと分かりやすいです。日本語の総合講座は責任共有やCSPM・CWPPなど全体像をつかむ入口、Cloud Security NOWはクラウドセキュリティ全般のハンズオン、AWS Security Best PracticesはAWSへ絞る構成です。

最初から3本すべてを見る必要はありません。クラウドセキュリティ自体が初めてなら全体像を1本で作り、その後に実務で使うAWSなどへ特化する方が重複を減らせます。

講座DB上の3候補は次の役割で分けられます。

- **クラウドネイティブ人材育成コース〖セキュリティ編〗**：総合。クラウドの責任共有モデルを扱う / ゼロトラストとセキュリティのシフトレフトを扱う

- **Cybersecurity: Cloud Security NOW! (2025)**：ハンズオン。クラウドセキュリティに関する内容をUdemy公式講座ページで確認

- **AWS Security Best Practices**：ハンズオン。AWS Securityに関する内容をUdemy公式講座ページで確認
