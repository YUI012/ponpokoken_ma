# AWS CLF ハンズオンなしでも受かる？3人の勉強法で検証

> **広告について：** 本記事にはアフィリエイト広告を含みます。購入前に価格・内容をリンク先でご確認ください。

## 結論

ハンズオンなしで進めて合格した例、ハンズオン講座を視聴しつつ操作部分をスキップした例、公式E-LearningとPing-tだけで合格した未経験例を確認した。一方でハンズオンなしでは知識定着が難しかったという振り返りもある。

結論として、**AWS CLFはハンズオンを省いても合格例があり、試験対策としては知識整理と問題演習だけでも成立する。ただし未経験者はサービスの違いを体感しにくく、定着面ではハンズオンが助けになる** と考えるのが妥当です。ここでいう「受かる」は試験合格の話です。操作経験を省いた場合、資格取得後の実務スキルは別途補う必要があります。

- 教材：参考書、問題演習

- 教材：AWS公式E-Learning、Ping-t
- 結果：CLF合格

## ハンズオンを省ける範囲を分けて考える

ハンズオンなしで合格した例があっても、すべての操作練習を削ってよいとは限りません。AWSやAzureの基礎資格では概念とサービス選定の理解、CCNAではCLIシミュレーション、Linux資格ではコマンドやパスの記述対策など、試験ごとに手を動かす代わりに残すべき学習があります。この記事では「AWS CLF ハンズオンなしでも受かる？」という疑問に絞り、上の3人の差を判断材料として確認します。

また、実務経験がある人は過去の操作経験を試験勉強で再利用できます。未経験者が同じ教材量をそのまま真似すると、用語を暗記できても挙動をイメージできないことがあります。3人の実例では「何を省いたか」だけでなく「何で代替したか」を見るのが重要です。この考え方を「AWS CLF ハンズオンなしでも受かる？」の判断に当てはめ、3人の違いを自分の学習条件と照らして見ていきます。

Azさんは、AWSはほとんど未経験という条件でCLF合格。学習期間は約10日、教材は参考書、問題演習でした。Udemy利用は記載なしです。

## 最終結論

ハンズオンなしで進めて合格した例、ハンズオン講座を視聴しつつ操作部分をスキップした例、公式E-LearningとPing-tだけで合格した未経験例を確認した。一方でハンズオンなしでは知識定着が難しかったという振り返りもある。

**AWS CLFはハンズオンを省いても合格例があり、試験対策としては知識整理と問題演習だけでも成立する。ただし未経験者はサービスの違いを体感しにくく、定着面ではハンズオンが助けになる**。合格だけを目標にするならハンズオンを減らせる資格はありますが、シミュレータ・コマ問・問題演習まで全部削るのは別問題です。合格後に実務で使う予定があるなら、試験対策で省いた操作経験を後から補う前提で学習計画を組む方が安全です。
