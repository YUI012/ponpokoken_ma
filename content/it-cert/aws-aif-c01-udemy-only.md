# AWS AI Practitioner Udemyだけで受かる？3人の合格者を比較

## 結論

AWS AI Practitionerは、**Udemy中心で合格した実例があります。** ただし、今回の3人だけでは「Udemy以外は一切不要」とまでは言い切れません。

1人目は1回目678点で不合格後、Udemy模擬試験4回分を2周して754点で合格しています。3人目はUdemyの動画講座と模擬試験を使い、約1週間で808点合格です。2人目は過去問を2周し、60〜70％から85％以上まで仕上げていますが、引用だけではUdemy利用を断定できません。

そのため、Udemyを主教材にする方法は十分現実的ですが、3人全員がUdemyだけで完結したとは確認できない、というのが正確です。

## 3人の実例

### 事例1
- 学習期間・時間：5日間・約5時間
- 問題演習：Udemy模試4回分を2周
- 結果：678点→754点で合格

### 事例2
- 学習期間・時間：1週間・1日1〜2時間
- 問題演習：過去問2周
- 結果：60〜70％→85％以上で合格

### 事例3
- 学習期間・時間：約1週間
- 問題演習：Udemy動画＋模試
- 結果：初受験808点で合格


## 3人を比べて分かること

3人に共通するのは、短期間でも問題演習を繰り返して正答率を上げていることです。単に動画を見るだけではなく、模試や過去問で仕上げています。

特に1人目は、不合格後にUdemy模試を2周して再受験し、点数を678点から754点へ上げています。3人目も動画講座と模試をセットで使っています。

つまり、Udemyを使うなら「動画を全部見る」より、**講義で範囲を掴み、模試を繰り返す**構成の方が今回の実例に近いです。

## 最終結論

AWS AI PractitionerはUdemy中心で合格した実例があります。特に、動画講座と模試を組み合わせ、短期間でも問題演習を繰り返した例が確認できます。

ただし、3人全員がUdemyだけで完結したとは確認できません。Udemyを主教材にしつつ、模試の正答率が伸びない分野だけ追加で確認する進め方が、実例からは再現しやすいです。
