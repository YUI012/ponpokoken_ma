## 結論

結論、本物の人間のように自律生活するAIをLINEへ入れることはできません。ただし、会話履歴・キャラクター設定・自発通知などを組み合わせ、自分専用のAIチャットBotを作ることは可能です。

「ChatGPT API × LINE Botを使えば、ちょっと無理そうなことまでできるんじゃないか？」という仮説で、実際に手を動かした3人の記事を見てみます。

## 改めて結論

- LINEをAIのフロント画面にできる
- 人格設定や会話履歴を持たせられる
- Webhook・API・データ保存の知識が必要

3人の体験を見ると、**「全部自動でできる」ではなく、「範囲を絞ればかなり実用的にできる」**という見方が近そうです。
