# AWS AI PractitionerはUdemyだけで受かる？合格者3人を比較

## 結論

AWS AI Practitionerは、**Udemy中心で合格した実例があります。** ただし、確認できた3人すべてがUdemyだけで完結していたわけではありません。

Udemy模試を2周して再受験に合格した人、Udemyの動画講座と模試で808点を取った人がいる一方、別の1人は過去問を2周して仕上げています。

Udemyを主教材にする方法は現実的ですが、模試で伸びない分野までUdemyだけに固定する必要はありません。

## 3人の実例

### 事例1
- 学習期間：5日
- 勉強時間：約5時間
- 問題演習：Udemy模試4回分を2周
- 結果：678点から754点へ上げて合格

### 事例2
- 学習期間：1週間
- 勉強時間：1日1〜2時間
- 問題演習：過去問2周
- 結果：1周目60〜70％から2周目85％以上まで仕上げて合格

### 事例3
- 学習期間：約1週間
- 問題演習：Udemy動画＋模試
- 結果：初受験808点で合格

## Udemyだけに絞るなら模試まで使う

3人に共通するのは、短期間でも**問題演習を繰り返していること**です。動画を見るだけで終わらせず、模試や過去問で正答率を上げています。

特に事例1は、初回678点で不合格になった後、Udemy模試4回分を2周して754点まで上げています。事例3も、動画講座だけではなく模試まで使っています。

Udemyを使うなら、講義を見終えることよりも、模試で間違えた分野を戻って確認する使い方の方が実例に近いです。

## 最終結論

AWS AI Practitionerは、Udemyを主教材にして合格を狙えます。実際にUdemy模試を反復して再受験に合格した例や、動画講座と模試で808点を取った例があります。

ただし、3人全員がUdemyだけで完結したわけではありません。Udemyで講義と模試まで進め、正答率が伸びない分野だけ追加で確認する使い方が現実的です。
