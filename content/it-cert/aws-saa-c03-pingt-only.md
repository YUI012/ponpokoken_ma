# AWS SAA Ping-tだけで受かる？3人の合格者を比較

## 結論

AWS SAAは、**Ping-tだけで合格した実例があります。** ただし、3人の実例を並べると「Ping-tだけを仕上げれば十分」とまでは言い切れません。

Ping-tだけを使い、購入した書籍も使わず学習した例がある一方で、Ping-tの模試で8〜9割取れていてもUdemyでは不合格だった例があります。別の例では、Udemy模擬試験を8割以上取れるまで反復しています。

そのため、Ping-tを主教材に絞る方法は成立しますが、最後に別形式の模試を1本入れて、見覚えではなく理解で解けているか確認する方が再現しやすいです。

## 3人の実例

### 事例1
- Ping-tの状況：模試で8〜9割
- Udemy利用：あり
- この実例から分かること：Ping-tで高得点でも別形式では不足が出る場合がある

### 事例2
- Ping-tの状況：Ping-tのみを使用
- Udemy利用：記載なし
- この実例から分かること：Ping-t中心でも合格した実例がある

### 事例3
- Ping-tの状況：記載なし
- Udemy利用：模擬試験を8割以上まで反復
- この実例から分かること：別形式の模試を繰り返して仕上げる例もある


## 3人を比べて分かること

一番重要なのは、教材数を増やすことではありません。Ping-tだけで進めた合格例があるため、最初から参考書・動画・問題集を何本も揃える必要はないと考えられます。

一方で、Ping-tで8〜9割取れていてもUdemyでは不合格だった例があります。同じ問題集を繰り返すと、問題文や選択肢を覚えて得点できる状態と、初見問題を解ける状態を区別しにくくなります。

3人目はUdemy模試を8割以上取れるまで反復しています。Ping-tを主教材にするなら、最後だけ別形式の問題を入れる構成が、今回の3例では最もバランスを取りやすい方法です。

## 合格者3人の学習例

### 1. Ping-tで8〜9割でもUdemyでは不合格

Ping-tの模試では8〜9割まで到達していましたが、Udemyでは不合格だった例です。Ping-t上の得点だけで仕上がりを判断しない方がよいことが分かります。

> しかも、PINGTの模試で8割9割取れてる段階でしたが、UDEMYでは余裕で不合格でした。Udemyの模試は「難しすぎる」とよく言われていますが、本当に難しいです。

### 2. Ping-tだけを使い、購入した書籍は使わず学習

> 今回使ったのはping-tと呼ばれるWeb教材のみ。ping-tの一番良いところは「SAAは無料で全問題できる」点。そして問題の質も悪くない。今回の試験をやるにあたり、改めてAWSにあるサービス全般を理解したかったため最初に下記書籍も購入した。
