## 先に結論

1か月での合格を狙うなら、教材を増やしすぎず、インプットと問題演習を短い周期で繰り返す進め方が取り組みやすいです。学習時間には個人差があるため、試験日から逆算して無理のない計画を組むことが重要です。

## 1か月で進める学習プラン

最初から細部を暗記するより、試験範囲の全体像をつかんでから問題演習へ移る方が、苦手分野を見つけやすくなります。

| 期間 | 学習内容 | 目安 |
|---|---|---|
| 1週目 | 試験範囲の把握・教材を1周 | 全体像をつかむ |
| 2週目 | 分野別の問題演習 | 苦手分野を確認 |
| 3週目 | 模擬問題・復習 | 間違えた理由を整理 |
| 4週目 | 弱点の再学習・総復習 | 本番形式に慣れる |

## 教材は増やしすぎない

短期間で進める場合は、動画講座や参考書を1つ、問題集を1つというように、軸となる教材を絞ると学習の進捗を管理しやすくなります。わからない部分だけ公式ドキュメントや追加資料で補う方法もあります。

## 参考情報

[AWS公式情報を見る](https://aws.amazon.com/jp/certification/certified-solutions-architect-associate/)

### AWS Skill Builder

AWS公式のデジタルトレーニングや試験準備リソースを確認できます。

[AWS Skill Builderを見る](https://skillbuilder.aws/)

## 問題演習で確認したいこと

- 正解だけでなく、不正解の選択肢がなぜ違うのか確認する
- 間違えた分野を記録し、数日後にもう一度解く
- 模擬問題の点数だけでなく、分野ごとの弱点を見る
- 試験直前は新しい教材を増やしすぎない

## まとめ

AWS SAAを1か月で狙う場合は、教材を絞り、問題演習と復習の回数を確保することがポイントです。学習経験やAWSの実務経験によって必要な時間は変わるため、自分の理解度に合わせて計画を調整してください。
