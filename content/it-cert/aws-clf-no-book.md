# AWS CLF 参考書はいらない？使わずに受かった3人を調査

> **広告について：** 本記事にはアフィリエイト広告を含みます。購入前に価格・内容をリンク先でご確認ください。

## 結論

AWS CLFは、参考書を使わずに合格した実例が3件確認できます。公式の無料学習、Ping-t、Udemy模擬試験といったオンライン教材だけでも学習は成立しています。

ただし、参考書を省くこととインプットを省くことは別です。3人とも公式教材や問題解説を使い、問題演習を繰り返しています。

## 3人の実例

### 事例1
- 教材：公式無料教材＋Ping-t＋Udemy
- 学習期間：1週間
- 学習時間：約13時間
- 結果：914点で合格

### 事例2
- 教材：Udemy＋Ping-t
- 学習時間：約30時間
- 参考書：使用なし
- 結果：合格

### 事例3
- 教材：公式E-Learning＋Ping-t
- 学習期間：2週間
- 開始時点：AWS・クラウド知識0
- 結果：合格

書籍なしでも、動画や解説付き問題集でインプットとアウトプットを両方確保している点は共通しています。

## 参考書を外すならオンライン教材の役割を分ける

公式教材は全体像、Ping-tは反復、Udemy模試は本番形式というように、教材ごとの役割を分けると参考書がなくても不足を補えます。

特にPing-tは無料で問題数が多い一方、同じ問題を覚えてしまう可能性があります。別形式の問題で理解を確認することが重要です。

## 最終結論

AWS CLFは参考書なしでも合格できます。3人の実例では、オンライン教材だけで必要なインプットと問題演習を組み立てています。

参考書を省くなら、公式教材で全体像を掴み、Ping-tや模試で解説まで理解する進め方が再現しやすいです。
