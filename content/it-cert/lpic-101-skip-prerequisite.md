# LPIC-101 Linux Essentialsを飛ばしてLPIC-101から始めていい？3人の取得ルートで検証

## 結論

Linux未経験・ほぼ未経験からLPIC-101に直接取り組み合格した例を複数確認した。Linux Essentials取得を前提にしたルートではなく、101教材や実機学習の中で基礎を補っている。

したがって、今回の3人からは **Linux Essentialsを受験せずLPIC-101から始めることは可能で、Linux初心者でも101対策の中で基礎を補える** と判断できます。重要なのは、前提資格の「受験」を飛ばすことと、その資格で扱う「基礎知識」を飛ばすことを分けて考えることです。

- 学習期間：約3週間
- 前提：未経験エンジニア
- 教材：Ping-t、Udemy、Gemini

### 別入門資格を挟まず101を4日で取得
- 結果：LPIC 101合格
- 学習期間：4日・24時間
- 前提：インフラ経験20年
- 教材：Ping-tなど

- 結果：LPIC-101合格（2回目）

- 前提：Linuxは月2〜3日触る程度
- 教材：入門本、Udemy、Ping-t

3人を並べると、取得順を固定しなくても合格できる一方、経験や学習時間には差があります。前の資格を持っているかだけでなく、次の試験で必要な基礎をどこまで埋められているかを見る必要があります。この記事では「LPIC-101 Linux Essentialsを飛ばしてLPIC-101から始めていい？」という疑問に絞り、上の3人の差を判断材料として確認します。

## 前提資格を飛ばすなら「不足知識だけ補う」

Linux Essentialsという試験を挟む必要性より、コマンド、ファイル操作、パッケージ管理などLPIC-101の基礎を学べる教材を選べるかが重要。完全初心者ほど、問題集だけでなく実機や入門教材を併用した方が理解しやすい。

前提資格を取らない場合でも、問題演習で分からない用語が多い、解説を読んでもサービスや仕組みの位置付けが分からない、という状態なら基礎へ戻るサインです。逆に、基礎問題を説明できるなら、資格取得の順番にこだわらず次の試験へ進む選択肢があります。この考え方を「LPIC-101 Linux Essentialsを飛ばしてLPIC-101から始めていい？」の判断に当てはめ、3人の違いを自分の学習条件と照らして見ていきます。
