# AWS SAA Ping-tだけで受かる？3人の合格者を比較

> **広告について：** 本記事にはアフィリエイト広告を含みます。購入前に価格・内容をリンク先でご確認ください。

## 結論

AWS SAAは、Ping-tを主教材に絞って合格した実例があります。実際に、Ping-t中心で2週間・724点、1ヶ月・861点で合格した例が確認できました。

ただし「Ping-t以外は一切不要」とまでは言えません。Ping-tのみで合格した人でも本番をPing-tより難しいと感じており、別の事例では公式問題やUdemy模試を補助的に使っています。

教材を増やしすぎる必要はありませんが、Ping-tを仕上げたあとに初見形式の問題で崩れないか確認してから受験する方が、3人の実例には合っています。

## 3人の実例

### 事例1
- 使った教材：Ping-t中心
- 補助教材：AWS公式の模擬問題・サンプル問題
- 学習期間：約1ヶ月
- 結果：合格

### 事例2
- 使った教材：Ping-t＋ChatGPT
- 学習期間：2週間
- 結果：724点で初回合格

### 事例3
- 使った教材：Ping-t＋Udemy模擬試験
- 学習期間：1ヶ月・約60時間
- 結果：861点で合格

3人ともPing-tを学習の中心にしていますが、補助教材の使い方は異なります。共通しているのは、Ping-tの問題演習を進めたうえで試験レベルの問題へ移っていることです。

## Ping-tだけで進めるなら初見問題だけは確認したい

1人目は教材としてPing-tのみを使い、最後にAWS公式の模擬問題とサンプル問題を追加しています。2人目もPing-t中心で2週間で合格していますが、本番はPing-tより難しかったと振り返っています。

3人目はPing-tを軸にしつつUdemy模試も使いましたが、Udemyについては「あってもなくてもよかった」と評価しています。つまり、Udemy自体が必須というより、Ping-tで覚えた答えだけでなく別形式でも解けるかを確認することに意味があります。

> 今回使ったのはping-tと呼ばれるWeb教材のみ。

> 試験前は必ずwell-architectは解いた方がいいと思います。ping-tと同じような問題が数問出ていましたので！

> ping-tがあれば1ヶ月でも十分戦えますので、

## 最終結論

Ping-tだけ、またはPing-tを中心にしてAWS SAAへ合格した実例は確認できます。教材を何冊も並行するより、まずPing-tを問題演習の軸にする方法は成立します。

一方で、Ping-tのみで合格した例でも本番との差は指摘されています。Ping-tを仕上げたら、公式問題や別形式の模試を一度だけ解き、初見でも判断できるか確認してから受験するのが再現しやすい進め方です。
