# AWSクラウドプラクティショナーは未経験でも合格できる？3口コミから現実的な期間を比較

## 結論

未経験からでも合格できます。ただし、1週間の最短例より、2週間〜1か月以上かけた初心者寄りの事例を基準にした方が、学習計画は立てやすいです。
