# AWS SAA 実務未経験でも受かる？未経験合格者3人を調査

## 結論

AWS実務未経験またはほぼ未経験の3人がSAAに合格した実例を確認した。782点、数値非公表で合格、746点と結果も確認できる。一方でIT経験や基本情報、CLF取得など前提条件は異なる。

結論として、**AWS実務未経験でもSAAに合格した実例は複数あるが、IT基礎や問題演習量によって必要な準備は変わる** と考えるのが妥当です。未経験から合格した実例は参考になりますが、「未経験」の範囲や既存知識は人によって違います。自分と近いバックグラウンドの事例を基準にしてください。

## 3人の実例

### 事例1
- 前提：IT経験約1年半、AWS経験は未経験。社内研修で2週間程度のAWSハンズオン経験あり
- 学習期間：12月初旬から学習し2026年1月合格
- 勉強時間：記載なし
- 結果：2回目782点で合格
### 事例2
- 前提：エンジニア歴3年弱、AWS実務はほぼなし、AWS資格なし、基本情報あり
- 学習期間：約1.5ヶ月
- 勉強時間：記載なし
- 結果：SAA合格
### 事例3
- 前提：社会人3年目の機械系エンジニア、IT・クラウド実務経験なし、基本情報あり。SAA前にCLF取得
- 学習期間：約1ヶ月半
- 勉強時間：約60〜70時間
- 結果：746点で合格

## 未経験合格例はあるが、前提条件を揃えて比べる

3人の事例から、AWS実務未経験でもSAAに合格した実例は複数あるが、IT基礎や問題演習量によって必要な準備は変わることが確認できます。ただし「未経験」の中身は同じではありません。業務で対象技術を使っていない人でも、別分野のIT経験、関連資格、研修、個人学習などを持っている場合があります。そのため、合格者の最短期間だけを切り取るのではなく、自分と近い前提条件の事例を見ることが重要です。

再現しやすいのは、最初に試験範囲の用語と全体像をつかみ、早い段階で問題演習へ移る進め方です。問題を解いて分からない論点を見つけ、解説や教材へ戻る往復を作れば、未経験でも学習範囲を絞りやすくなります。模擬問題の点数だけでなく、不正解の理由まで説明できるかを受験判断に使う方が安全です。この記事では「AWS SAA 実務未経験でも受かる？」という疑問に絞り、上の3人の差を判断材料として確認します。
