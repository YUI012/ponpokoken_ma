# wxPythonでデスクトップアプリを作る方法｜3つの実例

## 結論

3件ともwxPythonでwx.Appとwx.Frameを起点にGUIを構築し、ボタンや入力欄、フォルダ選択などのイベントを実装しています。ネイティブ系ウィジェットを使ったデスクトップアプリをPythonで作れることが確認できます。

wxPythonの最小構成は、wx.Appを作り、wx.Frameを表示し、MainLoopを開始する流れです。そこへPanel、Button、TextCtrl、ダイアログを追加します。

## 3人の実例

### 事例1

- 前提：wxPython入門実装者
- 実践：wx.Appとwx.FrameでHello Worldを表示し、TextCtrlとButtonのイベントを追加するデスクトップアプリを実装している。
- 結果：基本デスクトップアプリを作成

### 事例2

- 前提：wxPython業務利用者
- 実践：wxPythonとWxFormBuilderを組み合わせ、GUIを視覚的に作成してPythonコードから表示する構成を解説している。
- 結果：GUIビルダーで画面を作成

### 事例3

- 前提：wxPython初心者実装者
- 実践：wx.FrameとPanel、Buttonからフォルダ選択ダイアログを呼び、選択フォルダを後続処理へ使うGUIを作成している。
- 結果：フォルダ選択GUIを作成

3例から、wxPythonは簡単なフォームだけでなく、GUIビルダーやOS機能に近いダイアログへ広げられます。業務アプリではSizerを使ってレイアウトを管理すると画面変更に対応しやすくなります。
