# 損失関数はどう選ぶ？回帰と分類で違う理由

## 結論

損失関数は、モデルが「何をどれだけ間違えたか」を数値にし、学習で最小化する基準です。基本はタスクに合わせ、回帰ではMSE/MAE系、二値分類ではBinary Cross Entropy、多クラス分類ではCategorical Cross Entropyを候補にします。ただし外れ値や出力分布など、データの性質によって別の損失が適切なこともあります。

- 確認結果：外れ値を強く損失へ反映したい場合はMSEを選ぶという具体的な判断軸を確認。
- 判断材料：外れ値を強く損失へ反映したい場合はMSEを選ぶという具体的な判断軸を確認。

- 確認結果：MSEは外れ値に敏感、MAEは影響を抑えやすいなど性質も確認。
- 判断材料：MSEは外れ値に敏感、MAEは影響を抑えやすいなど性質も確認。


## 実例から分かること

- まずタスクが回帰か分類かで候補を絞る。
- 同じ回帰でも外れ値への強さなど損失の性質が違う。
- 学習に使う損失関数と、最終評価指標は必ずしも同じではない。
