# 線形回帰は何に使う？売上予測を例に初心者向け解説

## 結論

線形回帰は、売上・価格・需要などの「連続値」を予測し、各特徴量が目的変数へどう関係するかをシンプルに確認したい場面で使います。売上予測や住宅価格予測の実践例があり、まずベースラインとして線形回帰を置き、残差や誤差を見て非線形モデルへ進む判断にも使えます。

## 実例から分かること

- 目的変数が売上・価格などの連続値なら候補になる。
- 係数から方向性を説明しやすく、ベースラインにも使いやすい。
- 残差に非線形なパターンが残る場合は特徴量変換や別モデルを検討する。

## 最終結論

売上予測なら、まず広告費・価格・曜日・季節などの特徴量から連続値を予測するベースラインとして線形回帰を試す価値があります。精度だけでなく係数と残差を確認し、直線では捉えられない関係が強い場合に木系モデルなどへ比較対象を広げるのが分かりやすい進め方です。
