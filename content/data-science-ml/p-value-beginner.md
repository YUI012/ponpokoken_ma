# p値がわからない人向け｜仮説検定を判断の流れで理解する

## 結論

p値は「帰無仮説が正しい確率」ではない。帰無仮説を仮定したとき、観測結果と同じかそれ以上に極端な結果がどの程度起こるかを見る指標で、判断時は効果量・信頼区間・標本サイズも合わせて確認する必要がある。

- 実践者：新谷 正嶺
- 取り組み：1標本t検定をシミュレーションし、p値の意味と典型的な誤解を整理した。
- 確認結果：帰無仮説の下で極端な検定統計量が出る確率としてp値を確認している。
- 判断材料：記事テーマに直接関係する実装・比較・検証を行っている。

### 事例2

- 確認結果：p値を「帰無仮説の下で観測値以上に極端なデータが出る確率」と説明している。
- 判断材料：記事テーマに直接関係する実装・比較・検証を行っている。

### 事例3
- 実践者：新谷 正嶺

- 確認結果：有意差の有無だけでなく、差の大きさと不確かさを分けて読む必要性を示している。
- 判断材料：記事テーマに直接関係する実装・比較・検証を行っている。

## 実例から分かること

帰無仮説を先に置き、その仮定の下で観測結果の珍しさをp値で評価している。
p値だけで効果の大きさや重要性までは判断できないと整理している。

「p<0.05なら重要」「p>=0.05なら差がない」と単純化せず、効果量・信頼区間・研究設計も合わせて読む必要がある。
