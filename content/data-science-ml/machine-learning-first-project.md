# 機械学習初心者は最初に何を作る？おすすめ練習課題

## 結論

機械学習初心者の最初のプロジェクトは、Iris・Titanic・犬猫分類のように、データが小さく正解例が多い題材が向いています。重要なのは難しいモデルを作ることではなく、「データ確認→分割→学習→評価→改善」の1周を自分で完走することです。

- 判断材料：定番の小規模データで教師あり学習・3クラス分類の基本を体験できる。

- 判断材料：データ選定→ベースライン→学習→評価→改善の反復がプロジェクトの基本。


## 実例から分かること

- 小さい定番データセットなら情報が多く、詰まりにくい。
- 最初はモデル精度より一連の工程を自力で回せることが重要。
- 1回完走後に特徴量・モデル・評価方法を1つずつ変える。

## 最終結論

最初の1本はIrisの分類、Titanicの生存予測、犬猫画像分類などから1つ選び、Colabで最後まで動かしてください。データを読み、学習用/評価用へ分け、ベースラインを作り、指標を確認するところまで自力でできれば十分です。2本目から別アルゴリズムや特徴量改善へ進むと理解がつながります。
