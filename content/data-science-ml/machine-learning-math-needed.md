# 機械学習に数学はどこまで必要？初心者が先に学ぶ範囲

3事例に共通するのは、訓練データと評価データを分けてモデルを検証している。 Pythonで実際にモデルを動かし、評価値を確認している。

ただし、単一の評価値だけでモデルの良し悪しは決められない。
